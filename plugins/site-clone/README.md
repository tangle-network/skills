# Site Clone

Pixel-focused website migration from hosted platforms to self-hosted frontend frameworks.

## What It Does

Guides a full migration workflow:

- Rip rendered HTML, CSS, fonts, images, inline SVGs, and screenshots from the source site
- Extract the actual design system from CSS instead of guessing from screenshots
- Rebuild pages in Astro, Next.js, Vite, or another requested framework
- Preserve layout structure, typography, spacing, images, hover states, and responsive behavior
- Verify the result with side-by-side screenshots

## Usage

Triggers when cloning, migrating, rebuilding, copying, or replicating a website.
