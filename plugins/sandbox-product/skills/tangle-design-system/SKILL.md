# Tangle Design System compatibility entrypoint

This bundled skill remains available to Sandbox product builders. It routes to maintained owners rather than extracting a second design system from an old website.

Read the [Brand design bible](https://github.com/tangle-network/brand/blob/main/docs/design-bible.md) and its [implementation contracts](https://github.com/tangle-network/brand/blob/main/docs/brand-guidelines.md), then the public [Tangle Branded Designer workflow](https://github.com/tangle-network/skills/blob/main/plugins/tangle-branded-designer/skills/tangle-branded-designer/SKILL.md). For shared-component adoption, read [Sandbox UI Adoption](https://github.com/tangle-network/skills/blob/main/plugins/sandbox-ui-adoption/skills/sandbox-ui-adoption/SKILL.md).

Brand owns shared design policy and executable values. The public workflows apply that policy; an older installed skill with its own palette, type scale or motion table does not override it. Keep Sandbox transport, sessions, billing and authorization with the [Sandbox Product workflow](../sandbox-product/SKILL.md).

Prefer verified local checkouts and installed package documentation, and record their revisions. If a workflow cannot be fetched, inspect the real task, current components and [UI ownership contract](https://github.com/tangle-network/sandbox-ui/blob/main/UI-DIRECTION.md). Use already-reviewed local guidance where available; defer new brand decisions when their authority cannot be read. Continue independent source inspection without inventing values or forcing dependency upgrades.

For an existing surface, capture its real flow before editing. Reuse the maintained composition and confirm APIs against installed exports/types. Prove the changed flow on desktop and phone, including relevant keyboard, supported themes, failure and recovery states. Follow the [Brand evidence contract](https://github.com/tangle-network/brand/blob/main/docs/design-evidence-contract.md), separating functional results, independent craft review and target-user evidence. Record unrun checks and unverified publication or deployment honestly.

Retain this slug and bundled path until actual readers have been inventoried and migrated. A repository entry proves discoverability, not installation on a host.
