# Tangle Blueprint Iframe App

Build hosted blueprint product UIs that run as sandboxed iframe apps inside Tangle Cloud.

## What It Does

Guides the full iframe-app path:

- Scaffold or adapt a Vite/React blueprint product UI
- Use the Tangle iframe bridge instead of direct wallet access
- Publish `blueprintUi.externalApp` metadata with declarative permissions
- Wire local development through the Tangle Cloud blueprint UI catalog
- Deploy with Cloudflare-compatible frame and security headers
- Verify wallet, job, mode, and browser behavior before shipping

## Usage

Triggers when building hosted blueprint apps, embedding a blueprint UI in Tangle Cloud, adding iframe mode, wiring a blueprint app manifest, or implementing parent-bridged wallet flows.
